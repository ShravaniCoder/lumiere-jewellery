# Lumière page file structure
Each page has its own JSX file: Home.jsx, Shop.jsx, Collections.jsx, CollectionProducts.jsx, ProductDetail.jsx, Cart.jsx, Checkout.jsx, Story.jsx, Contact.jsx and TrackOrder.jsx.
Shared navigation/footer and reusable components are in Layout.jsx. Cart and wishlist state remain shared in App.jsx. Removed the redundant standalone Contact Us link from the mobile menu.
